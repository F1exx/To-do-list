# To-Do List Web Application

Autors: Romans Iglins
Klase: 12. klase

## Projekta apraksts

Šī ir tīmekļa lietotne uzdevumu pārvaldīšanai.  
Lietotājs var reģistrēties, pieslēgties savam kontam un pārvaldīt savus uzdevumus.

## Galvenās funkcijas

- Lietotāja reģistrācija un autorizācija
- Uzdevumu pievienošana
- Uzdevumu dzēšana
- Uzdevumu atzīmēšana kā izpildīti
- Datu glabāšana SQLite datubāzē

## Izmantotās tehnoloģijas

- HTML
- CSS
- JavaScript
- Python Flask
- SQLite

## Programmas palaišana

1. Instalēt Flask bibliotēku
2. Palaist serveri ar komandu:
   python app.py
3. Atvērt pārlūkā:
   http://127.0.0.1:5000
